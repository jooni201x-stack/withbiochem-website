# WITHBIOCHEM 회사 소개 웹사이트

화장품 펩타이드 원료 B2B 공급사 **위드바이오캠(WITHBIOCHEM)** 공식 소개 사이트입니다.

## 기술 스택

- **Next.js** (App Router) + TypeScript
- **Tailwind CSS** v4
- **Framer Motion** — 스크롤/호버 애니메이션
- **Lucide React** — 아이콘

## 섹션 구성

1. **Hero** — 브랜드 메시지, 고순도·COA·국내합성 하이라이트
2. **회사 소개** — 미션, Passion / Professional / Smart / Technology
3. **주요 제품** — Palmitoyl Tripeptide-5, GHK-Cu, PT-1, Dipeptide-2, Custom Synthesis
4. **공급 강점** — Quality / Speed / Flexibility, 거래 정보
5. **문의** — 연락처 및 메일 연동 문의 폼

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 열어 확인하세요.

```bash
npm run build   # 프로덕션 빌드
npm start       # 빌드 결과 실행
```

## 참고

- 콘텐츠는 `WC브로셔_합성서비스_펩타이드_B2B_FN.pdf` 브로셔를 기준으로 구성했습니다.
- 임상·효능 수치는 공개 문헌/제조사 자료 기반 B2B 참고용이며, 사이트 하단에 면책 문구를 포함했습니다.
